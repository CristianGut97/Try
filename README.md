# Portafolio y Laboratorio de Aprendizaje - Cristian

Este repositorio contiene mi sitio web personal y una colección de ejercicios prácticos desarrollados durante mi proceso de aprendizaje en diseño y desarrollo web.

## 🚀 Acerca de este proyecto
Soy Cristian, diseñador apasionado por lo visual y el código. Este proyecto refleja mi transición hacia el desarrollo web, combinando creatividad con estructura técnica. A mis 27 años, busco unir diseño y funcionalidad para crear sitios impactantes, accesibles y eficaces.

## 📂 Estructura del Proyecto

El proyecto ha sido organizado para facilitar la navegación y el mantenimiento:

- **`website/`**: El núcleo de mi presencia digital.
  - `index.html`: Página principal de bienvenida.
  - `acercaDe.html`: Mi historia y visión.
  - `experiencia.html`: Trayectoria profesional.
  - `servicios.html`: Qué puedo ofrecer.
  - `contacto.html`: Formas de conectar conmigo.
  - `style.css`: Estilos visuales del sitio.
- **`ejercicios-js/`**: Laboratorio de lógica de programación.
  - Ejercicios sobre bucles anidados, funciones, y talleres prácticos (Calculadoras, lógica matemática).
- **`practicas/`**: Zona de pruebas para experimentar con nuevas etiquetas HTML y estilos CSS.
- **`notas/`**: Repositorio de conocimientos sobre MongoDB, SQL y Python.
- **`assets/`**: Recursos multimedia y assets del proyecto.

## 🛠️ Tecnologías Utilizadas
- **Frontend:** HTML5, CSS3, JavaScript (ES6+).
- **Base de Datos:** Fundamentos en SQL y MongoDB.
- **Otros:** Nociones básicas de Python.

## 📖 Cómo explorar este repositorio
1. **Sitio Web:** Navega a la carpeta `website/` y abre `index.html` en cualquier navegador moderno.
2. **Lógica JS:** Los archivos en `ejercicios-js/` pueden ser probados directamente en la consola del desarrollador del navegador o mediante un entorno de ejecución como Node.js.
